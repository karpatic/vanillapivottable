What changed

  • Axis containers now host dedicated sortable lists instead of mixing draggable pills and hidden filter popovers in the same table cell.
  • Drag starts from an explicit handle, which avoids accidental filter-menu clicks and makes the live UX easier to control.
  • Refreshes are debounced, drop targets stay visibly open when empty, and local asset URLs are versioned for GitHub Pages cache busting.
